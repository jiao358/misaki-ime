# Misaki 关系助手 MVP 使用指南

## 用户路径

1. 打开 Misaki 主应用，在“关系助手 → 关系对象”中用昵称创建对象；
2. 在人物列表点选当前沟通对象，选择会话保持 30 分钟；
3. 聊天时主动复制对方的一条消息；
4. 在输入法候选栏点击：
   - “记一下”：调用记忆提取，确认事实/推测和类别后加密保存；
   - “妙回”：召回少量相关记忆，生成自然、幽默、克制三条候选；
5. 点击“插入输入框”后仍由用户决定是否发送；点击“不合适”会更新该对象的本地表达偏好；
6. 回到人物管理页，可查看、编辑、删除记忆，并将记忆转成承诺提醒；
7. 用户可以导出全部关系数据，或一键彻底删除本地人物、记忆和提醒。

## 本地开发

Android 模拟器默认请求 `http://10.0.2.2:8000`：

```bash
./gradlew assembleDebug --quiet
./gradlew test
```

真机调试或发布时通过 Gradle 属性指定 HTTPS 后端：

```bash
./gradlew assembleRelease \
  -PMISAKI_API_BASE_URL=https://api.example.com
```

## 隐私边界

- 不申请通讯录权限，不映射真实联系人；
- 不在后台监听其他应用或自动读取全量聊天；
- 只有用户点击“记一下”或“妙回”时才使用最近主动复制的文本；
- 长期保存的是用户确认后的短记忆，内容使用 Android Keystore AES-GCM 加密；
- 服务端反馈只包含请求 ID、候选 ID 和动作，不包含最终发送文本；
- 关系数据库和偏好文件不进入 Android 云备份或设备迁移。
